# 约会地点推荐 H5

一个可直接在浏览器使用的约会地点推荐 H5 页面。输入双方位置、选择地点偏向和约会偏好后，页面会推荐约会地点并规划路线。

## 在线使用

H5 页面已支持直接使用：

- Vercel: https://date-planner-three-sigma.vercel.app
- 输入用户 A 和用户 B 的位置
- 选择「折中位置」「离 A 近一点」或「离 B 近一点」
- 选择公园、咖啡、电影、餐厅等约会偏好
- 查看推荐地点、A/B 距离或路线时间
- 查看双方到目的地的路线规划

## 本次修改说明

- 修复百度地图 JS API 在部分浏览器环境下的 CORS 和加载问题。
- 改为通过百度地图 Web Service + JSONP 调用地点搜索、地理编码和路线规划。
- 修复「离 A 近一点 / 离 B 近一点」策略不准确的问题：
  - 优先在对应用户附近搜索地点。
  - 对候选地点按真实路线时间二次排序。
  - 推荐卡片展示 A/B 的距离或路线时间。
- 增加 API 失败时的明确提示和降级结果，避免页面直接不可用。
- 增加 Vercel 根路径访问配置，部署后打开站点根路径即可使用。

## 本地打开

直接打开 `date-planner.html` 即可使用。
